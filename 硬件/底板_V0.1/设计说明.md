# 四轴底板原理图 V0.1

按用户提供的 TYPE-C 核心板原理图设计。接口为四轴、5V 共阳光耦驱动器、3.81mm 绿色端子，每轴 4 位：1 PUL+、2 PUL−、3 DIR+、4 DIR−。保留 USART1 与上位机交互。

## 查看和编辑

- `四轴运动控制底板_V0.1.pdf`：三页电路原理图。
- `源文件/sheet1.svg` 至 `sheet3.svg`：可编辑矢量图；同名网络在三页之间电气相连。
- `源文件/draw_schematic.py`：生成器，需要 Python reportlab。
- `连接表.csv`、`引脚分配.csv`、`BOM.csv`：连接关系、引脚和初步采购清单。

这是电路方案草图，不是 KiCad/立创 EDA 工程；尚未进行 EDA 电气规则检查、PCB 布局或实物测试，不能直接投板。

## 引脚

|轴|PUL|定时器|DIR|
|---|---|---|---|
|X|PA0，H4.5|TIM2_CH1|PB12，H5.20|
|Y|PA6，H4.11|TIM3_CH1|PB13，H5.19|
|Z|PB6，H5.7|TIM4_CH1|PB14，H5.18|
|A|PA8，H5.16|TIM1_CH1|PB15，H5.17|

四个定时器独立设置周期，避免同一个定时器的多个 CH 共用周期限制独立轴频率。多轴插补同步、加减速及精确脉冲计数由后续固件实现。

## 电机输出

8 路 AO3400A 低端开关，每路栅极串 100Ω、对地 10kΩ下拉；SOT-23 引脚 1=G、2=S、3=D。MCU 高电平导通，驱动器光耦点亮；复位或低电平关闭。PUL−/DIR− 是开漏式下拉输出，并非差分输出。

驱动器必须支持 5V 共阳输入并内置限流；如需要外置限流电阻，按驱动器手册在对应线缆中串联。尚未取得具体驱动器型号，最高脉冲频率、脉宽、DIR 建立/保持时间和输入电流待确认和实测。首版不含 ENA、限位、回零、急停或主轴接口。

## 电源与串口

J7 接外部稳压 24V（1 脚为正，2 脚为地）。经慢断保险丝 F2 后送至 U1（TSR 1-2450），C3 为 22µF/50V 输入电容。U1 输出 5V，通过 JP1 接核心板 H5.3。模块额定输出 1A，实际带载和温升待实测。J7 按极性接线，模块输入瞬态不得超过 36V。

J1 仍接外部稳压 5V，经 F1 给四轴驱动器输入光耦供电。J1 与 J7 共地，两条供电正线分开。核心板 USB VBUS 与板上 5V 直连，接入带供电的 USB 前先拔掉 JP1，避免 USB 与降压模块输出并联。

J6 为 3.81mm 3 位串口端子：1=卡 TX（PA9，经100Ω），2=卡 RX（PA10，经100Ω，10kΩ上拉至3.3V），3=GND。电脑使用 3.3V 电平 USB 转 TTL 模块：卡 TX 接模块 RX，卡 RX 接模块 TX，地相连；不接模块 VCC。不是 RS232 或 RS485 接口，按短距离本地通信使用。USB 原生接口与 SWD 均保留。波特率及交互协议待固件定义。

核心板两侧排针编号严格对应原图 H4/H5；实际排距、针1方向、端子型号和封装须在 PCB 前实测确认。原图 PC14/PC15 接板上低速晶振，不应当作空闲 GPIO 使用。
